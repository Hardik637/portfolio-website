## 🎨 Visual Identity & Design Direction

- **Style:** Modern Creative Developer Portfolio (Editorial, Contemporary, Asymmetric).
- **Themes:** Dual-theme system (Obsidian Dark `#101110` / Warm Parchment Light `#F4F3EE`).
- **Accent:** Electric Lime (`#C6F36A`) used with surgical restraint for primary actions, active indicators, and status badges.
- **Typography:** Space Grotesk (Headings), Inter (Body & UI), Playfair Display (Editorial Accents).
- **Standards:** WCAG AAA contrast compliance, zero-FOUC theme switching, GPU-accelerated motion, full `@media (prefers-reduced-motion)` support.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Hardik637/portfolio-website.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
